# ⚖️ Oficina Jurídica Profesional - Landing Page

Esta es la plataforma digital oficial del **Despacho Jurídico del Lic. Mario José López Villatoro**, diseñada para ofrecer una experiencia de usuario fluida, profesional y optimizada para dispositivos móviles.

## 🚀 Características del Proyecto
- **Diseño Responsivo:** Adaptado para celulares, tablets y computadoras.
- **Navegación Dinámica:** Sistema de vistas (SPA) mediante JavaScript para una carga rápida sin recargar la página.
- **Interacción Directa:** Integración de botones de acción rápida para WhatsApp, llamadas telefónicas y correos electrónicos.
- **Estética Profesional:** Uso de tipografías elegantes como *Playfair Display* y *Lobster* con una paleta de colores corporativa (Dorado y Azul Oscuro).

## 🛠️ Tecnologías Utilizadas
*   **HTML5:** Estructura semántica del sitio.
*   **CSS3:** Diseño personalizado con variables, Flexbox y CSS Grid.
*   **JavaScript (Vanilla):** Lógica para el manejo de vistas y despliegue de detalles de trámites.
*   **Google Fonts:** Tipografías integradas para legibilidad y estilo.

## 📂 Estructura de Archivos
*   `index.html`: Contiene la estructura, los estilos (CSS) y la lógica (JS).
*   `Mariolopez.jpeg`: Imagen principal de presentación.
*   `img.html`: Placeholder o contenedor de logotipos.
